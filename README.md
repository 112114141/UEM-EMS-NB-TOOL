# 🎓 应急管理大学教务管理系统抢课工具

> 选课如打仗，手速定生死。本工具是你选课战场上的自动化武器。

## 🤔 这是什么

一个帮你抢课的小工具。选课开放瞬间，它比你手快 100 倍，正如其名：NB TOOL。

**原理很简单**：填个 Cookie 和课名，它在开放时间前就开始疯狂提交选课请求，抢到为止。抢不到？没关系，它还会帮你蹲守，等别人退课了立刻补上。

## ✨ 功能

- ⚡ **秒抢**：开放时间前提前开火，5 线程并发盲提交，快到飞起
- 🎣 **捡漏**：秒抢没中？自动转入蹲守模式，有人退课秒补位
- 🕐 **时间校准**：自动从服务器校准时间，电脑时间不准也不怕
- 🔍 **接口自动探测**：填个 Cookie 就行，不用手动抓包（大概率）
- 🖱️ **傻瓜式 UI**：双击 exe 就能用，不装 Python，不装任何依赖

## ⚙️ 抢课策略

```
开放时间前 3 秒
    ↓
秒抢模式（5线程并发盲提交）
    ├─ 抢到 → ✅ 结束
    └─ 课余量归零 → 自动转入捡漏
              ↓
        捡漏模式（1.5秒/次查余量）
              ├─ 有人退课 → 立即提交 → ✅
              └─ 一直等...
```

## ⚠️ 注意事项

- Cookie 有效期一般 1~2 小时，过期了重新登录复制一个
- 别把频率调太高，教务系统也许会封你 IP？
- 本工具仅供学习交流，抢课有风险，使用需谨慎
- 如果抢不到，应该是你人品问题，不是工具问题 😏

## 🛠️ 技术栈

- tkinter（UI，Python 自带）
- PyInstaller（打包成单 exe）
