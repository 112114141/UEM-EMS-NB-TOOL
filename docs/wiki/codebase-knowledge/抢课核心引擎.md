# 抢课核心引擎

## 概述 <!-- category:overview -->
本模块提供教务系统自动抢课的完整能力，涵盖服务器时间校准、Cookie 有效性检查、选课接口自动探测、目标课程定位、精准倒计时、多线程并发秒抢以及持续捡漏等全流程。通过单一 GrabCore 类封装全部逻辑，支持外部注入日志函数与停止信号，可由 GUI 或脚本驱动。

## 架构设计 <!-- category:architecture_design -->
GrabCore 是唯一核心类，封装全部抢课逻辑。核心状态：requests.Session（复用连接）、time_offset（时间偏移）、query_url/select_url（探测接口）、target_course（目标课程）。方法分三层：基础设施层（calibrate_time/check_cookie）负责时间校准与会话保活；探测层（detect_apis/_parse_page/find_course/_extract_courses）用正则自动识别接口与解析课程；执行层（submit_select/run/_rush/_scavenge）负责提交选课与结果判定。run() 为编排入口，依次执行校准→检查→探测→定位→倒计时→_rush()秒抢→_scavenge()捡漏。_rush() 用 ThreadPoolExecutor(max_workers=5) 并发提交，_scavenge() 单线程轮询。仅依赖标准库与 requests。

requests（HTTP 会话）、concurrent.futures.ThreadPoolExecutor（5 线程并发秒抢）、re（接口正则探测）、datetime/email.utils.parsedate_to_datetime（服务器时间校准）。

## 编码规范 <!-- category:coding_conventions -->
1. 类名 PascalCase，方法名 snake_case，私有方法以单下划线前缀（如 _parse_page、_rush）。
2. 所有网络请求统一经 self.session 发起，复用连接与 Cookie，超时均显式设置。
3. 异常处理采用 try/except 包裹 + 静默降级（返回 False/None），保证主流程不中断。
4. 接口字段兼容多种命名（如 kcmc/courseName/KCMC），通过候选键列表逐一匹配。
5. 日志统一经 self.log() 输出带时间戳消息，支持外部注入 log_func。

## 配置与命令 <!-- category:unique_setup_and_commands -->
本模块为 leaf 模块，无特有构建命令。运行时通过 GrabCore(cookie, base_url, log_func) 构造，调用 run(open_time, advance_seconds, keyword, stop_check) 启动抢课。默认 base_url 指向 https://jw.cidp.edu.cn，可按需替换为其他正方教务系统地址。
