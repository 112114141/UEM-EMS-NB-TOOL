# 图形界面

## 概述 <!-- category:overview -->
本模块提供抢课工具的图形用户界面，基于 tkinter 构建。包含选课信息输入（Cookie、课程名）、开放时间设置（年月日时分秒）、提前量配置、开始/停止控制及实时彩色日志显示等功能，通过后台线程驱动 GrabCore 核心引擎执行抢课，避免阻塞界面。

## 架构设计 <!-- category:architecture_design -->
GrabUI 为本模块唯一核心类，持有 tkinter 根窗口与全部控件引用。_build_ui 统一编排界面，按选课信息、时间设置、控制按钮、日志四区分组。start_grab 收集并校验输入后，以 threading.Thread 启动 _run_grab 后台线程调用 GrabCore.run；线程通过 self.log 回调（经 root.after 调度至主线程）写入日志，stop_flag 控制停止。_font/_mono_font 为模块级字体辅助函数，按平台选择字体族。

## 编码规范 <!-- category:coding_conventions -->
1. 控件构建集中在 _build_ui 方法中，按功能区域用 LabelFrame 分组
2. 私有方法以单下划线前缀（_build_ui、_run_grab、_on_finish、_center_window、_get_log_tag、_update_status）
3. 跨线程 UI 更新通过 root.after(0, callback) 调度到主线程，禁止直接操作控件
4. 字体经 _font/_mono_font 辅助函数统一生成，按平台适配字体族
5. 日志按内容关键字自动着色（success/error/warning/info 四类标签）
