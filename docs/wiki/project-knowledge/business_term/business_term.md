# 业务术语表

## 概述
本术语表收录抢课工具涉及的核心业务概念，覆盖选课竞争策略、会话凭证、时机控制与接口识别等领域，旨在统一业务语义，便于需求沟通与功能演进。

## 术语列表

### 秒抢
- **定义**：选课开放瞬间以多线程并发高频提交选课请求的策略，目的是在极短窗口内抢到有限名额。
- **别名**：Rush grab、盲提交

### 捡漏
- **定义**：秒抢未成功后转入的持续轮询模式，周期性查询课程余量，有人退课时立即提交选课请求补位。
- **别名**：Scavenge、蹲守模式

### 时间校准
- **定义**：通过比对服务器 HTTP 响应头 Date 与本地时间，计算偏移量并修正本地时钟基准，确保抢课时机精准。
- **别名**：Time calibration、服务器对时

### 接口探测
- **定义**：自动解析教务系统选课页面 HTML，用正则识别查询接口和选课接口 URL，免去手动抓包配置。
- **别名**：Auto API detection、接口自动识别

### 提前量
- **定义**：在选课开放时间前提前开始提交请求的秒数，用于弥补网络延迟与请求往返耗时。
- **别名**：advance_seconds、提前开火秒数

### Cookie
- **定义**：教务系统登录会话凭证，用于维持已登录状态，有效期一般 1~2 小时，过期需重新登录获取。
- **别名**：会话凭证、登录态

### 开放时间
- **定义**：教务系统开放选课操作的具体时间点，是秒抢启动的基准时刻。
- **别名**：open_time、选课开放时刻

### 课余量
- **定义**：课程当前剩余可选名额，归零表示已满，捡漏模式据此判断是否触发提交。
- **别名**：remaining、余量、容量
